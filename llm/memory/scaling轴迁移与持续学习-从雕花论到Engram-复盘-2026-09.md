# 复盘：《Scaling 轴迁移与持续学习：从"雕花论"到 Engram》五周后

- memo 写于 2026-08-02（memo 仓库 `llm/memory/`），来源是 8 月中旬 `~/code` 目录里一段关于 Engram 与 LLM memory 体系的长讨论。
- 复盘日期 2026-09-10，依据是 DeepSeek-V4.1-Flash 技术报告（9 月发布）和公开资料。

## 一、memo 里可以核对的预测，逐条打分

| # | memo 的说法 | 五周后的事实 | 结果 |
|---|---|---|---|
| 1 | Engram 是"V4 前瞻"，会进旗舰模型 | V4（6 月）没用；V4.1-Flash（9 月）用了，196B 参数，是第一个搭载 Engram 的对外模型 | 方向对，时间晚一版 |
| 2 | 固定参数预算下 MoE 与 Engram 配比有 U 型最优，原论文给的甜点约 20–25% | V4.1：196B / (552B + 196B) = 26% | 命中 |
| 3 | "100B 记忆表可卸载到主机 DRAM，吞吐损失 <3%"，确定性寻址可预取 | V4.1 推理时 Engram 表放主机内存，用后台 RDMA 预取，第一个模块的预取与第一层计算重叠。规模从论文的 100B 放大到 196B | 命中，且规模翻倍 |
| 4 | 追踪信号 2："V4 的 Engram 记忆表是否支持训后更新" | 报告没有任何训后更新、可编辑、按用户分表的内容。表和其他权重一样用 Sinkhorn 动量更新一起训，RL 阶段甚至常驻 GPU 显存。定位仍是"静态知识压缩" | 未兑现 |
| 5 | Engram 让"改表不动推理权重"在架构上可想象，是持续学习的"收纳处" | DeepSeek 自己没朝这个方向走。V4.1 结论章的未来方向是数据合成、RL 规模化、模型与 harness 协同设计，全文没有 continual learning 字样 | 仍是推断，无新证据 |
| 6 | 追踪信号 1：CL-Bench 上是否出现"随经验单调变强且不遗忘" | CL-Bench（arXiv 2606.05661）已有 Snorkel 维护的排行榜，评的是 ICL 到专用记忆系统等多种 agent 架构，尚无权重内方案上榜 | 无变化 |
| 7 | 追踪信号 2：Hope / Nested Learning 是否进 Gemini 主线 | Google 仍是"计划整合进未来 Gemini"，公开资料里 Hope 仍是小规模实验 | 无变化 |
| 8 | 睡眠固化路线"个人最看好" | 6 月两篇论文（2606.03979、2605.26099）之后没有出现前沿规模验证 | 无变化 |
| 9 | "研究在赌权重内，产品全在权重外" | V4.1 是这句话的又一个样本：DeepSeek 把力气花在 KV cache 压缩（让上下文这个"权重外工作记忆"更便宜）和 agent 数据流水线上，没碰权重内学习 | 加强 |
| 10 | 雕花判别："这项工作会随规模复利，还是被规模冲刷掉" | V4.1 全部架构改动（CED、CSA2、FP4 KV、Bounded Replay）都是 scale-enabler，和 memo 举的 MLA、FP8 同类 | 框架适用 |

## 二、Engram 在 V4.1 里到底带来了多少收益

**报告没有给出 Engram 的消融实验，收益无法从 V4.1 报告中量化。** 能确定的只有：

- 唯一的定性表述是 "to strengthen model capabilities"。
- 基座模型用 1/4 激活参数达到 V4-Pro-Base 水平，但这是 Engram、数据质量、CED、多模态训练的合并效果，报告自己归因于"数据质量"。
- 唯一的 Engram 数字来源仍是 1 月原论文的 27B 实验：知识类 +3 到 +4 分，推理类 +3 到 +5 分。这个增益是否在 552B 上保持，报告没说。
- 报告为 Engram 付出的工程成本是可见的：196B 参数、专用并行组、FP8 表、Sinkhorn 优化器、RDMA 预取路径。DeepSeek 愿意付这个成本，本身说明内部消融是正的，但外界看不到数字。

## 三、这篇 memo 的收益是什么

按"判据比结论长寿"的标准来看：

1. **结论层**：关于 Engram 会进旗舰、配比、卸载到 DRAM 三条都对了。关于"持续学习"的整条推断线（信号 1、2 和第六节的展望）五周内没有任何新证据，不算错，但也没有兑现。
2. **判据层**：memo 提供的两个筛选器，"随规模复利还是被冲刷"和"信号住在哪"，用来读 V4.1 报告是直接可用的。V4.1 后训练章"数据流水线收益远大于算法创新"和 memo 第三节"搭 gym 是新时代的标注"是同一件事。
3. **一个需要修正的地方**：memo 把 Engram 定位为持续学习的"收纳处"。V4.1 的实际用法说明 DeepSeek 自己把它当作"用便宜的 DRAM 扩知识容量、把 GPU 留给计算"的成本工具，和 KV cache 压缩是同一个动机。持续学习的解读是外界推断，目前没有 DeepSeek 的行动支持。追踪信号 2 应该改写为：**DeepSeek 或任何厂商是否发布过"Engram 表可以在不重训骨干的情况下更新"的证据**。
4. **对读书计划的直接用处**：memo 的阅读清单和 V4.1 报告的引用列表交集只有 Engram 一篇。这说明 V4.1 报告和"持续学习"这条线基本不相交，读 V4.1 不需要先读那份清单。

## 四、下一次复盘时看什么

- DeepSeek 是否发 Engram 单独的更新论文，或 V4.1 之后的模型是否把 Engram 表做成可替换、可按领域挂载。
- CL-Bench 排行榜上是否出现权重内方案。
- 睡眠固化路线是否有 100B 以上规模的结果。
